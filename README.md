# nixos-old-config (deprecated)

> **Deprecated — personal use only.**

This repository contains my old NixOS setup, which was managed with a single
plain `configuration.nix` file. **This approach is deprecated for my personal
use** and is no longer maintained.

I have moved to a flake-based configuration, which now lives here:

**https://github.com/phaitonican/nixos-config**

Please use the flake repository above instead. The files in this repo are kept
only for historical reference and should not be used as a starting point for
new setups.
